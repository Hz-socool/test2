## Goal

Independently evaluate the complete beta against the PRD.

## Work

- Build and run the full automated suite.
- Execute Golden Fixtures and edge cases across all configured widths.
- Inspect source preservation, visual fidelity, Instance safety, Wrap, Min/Max, breakpoint structure, and report accuracy.
- Record each failure with reproduction steps, expected/actual result, severity, and affected fixture.
- Produce a beta go/no-go report.

## Acceptance

- Test evidence is committed and reproducible.
- No critical defect is omitted or silently downgraded.
- The report clearly identifies release blockers and non-blocking follow-ups.
