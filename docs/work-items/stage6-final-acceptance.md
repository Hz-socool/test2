## Goal

Issue an independent final release recommendation.

## Work

- Rebuild the release candidate from a clean checkout.
- Rerun all Golden Fixtures, regressions, and mandatory breakpoint tests.
- Verify all Stage 4 critical/high findings are resolved.
- Compare results with the PRD quality gates and produce a final go/no-go report.

## Acceptance

- The report includes reproducible evidence and unresolved risks.
- A go recommendation requires zero critical loss and successful mandatory responsive validation.
- If any release blocker remains, recommend no-go and identify the exact remediation required.
