## Goal

Resolve QA findings and prepare a release candidate.

## Work

- Read the Stage 4 QA evidence and fix all critical/high-severity defects.
- Add regression tests for every fixed defect.
- Improve error handling, performance safeguards, setup instructions, and user-facing warnings.
- Produce a buildable release candidate and a concise handoff for final QA.

## Acceptance

- Critical/high QA findings are fixed or explicitly blocked with evidence.
- The full developer test suite passes.
- Release setup and known limitations are documented.
